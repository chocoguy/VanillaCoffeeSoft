Anime tracking API

Endpoints

  • GET /api/AniTrak/Anime/{id} — anime by id
  • GET /api/AniTrak/Anime/search?q=... — search (falls back to MAL)
  • GET /api/AniTrak/Anime/seasonal — current season
  • GET /api/AniTrak/Anime/{malId}/recommendations — recommendations
  • GET /api/AniTrak/Anime/{malId}/related — related anime
  • GET /api/AniTrak/Anime/{malId}/pictures — pictures
