
# VanillaCoffeeSoft

UNDER CONSTRUCTION

## What is this?

This is the code for the public API Hosted at https://vanillacoffeesoft.net/
It's basically a multi purpose backend for all of my frontend apps

## What runs this?

It's built with C# Using the ASP Net core Web API Framework, It uses SQLite for simple relational data storage with dapper as the interface of choice


## What does it do?

Currently this serves as the backend for 3 of my front end apps
All of these are iOS apps built with SwiftUI

- AniTrak
- WindyPoints
- BlueTrains
